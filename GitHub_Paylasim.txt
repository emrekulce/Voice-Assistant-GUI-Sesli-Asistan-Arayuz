[![Zero Dependencies](https://img.shields.io/badge/Dependencies-Standard%20Library%20Only-orange.svg?style=for-the-badge)]()

Kendi yapay zeka sesli asistanını (AI Voice Assistant) geliştiren geliştiriciler için tasarlanmış; **modern, şeffaf (glassmorphic), 60 FPS animasyonlu ve sürükle-bırak destekli kayan arayüz (Floating HUD Overlay)** şablonu.

Tamamen **Python standart kütüphaneleriyle** geliştirilmiştir. Çoklu işlemci mimarisi (`multiprocessing`) sayesinde asistanınız arka planda ses kaydederken, LLM (Büyük Dil Modeli) düşünürken veya ses sentezlerken (TTS) arayüz **asla donmaz (0ms lag)**.

## ✨ Öne Çıkan Özellikler

- 💎 **Modern Glassmorphic Tasarım:** Şeffaf pencereler, yumuşak yuvarlatılmış köşeler, durum rozetleri (pill badge) ve neon ışıma efektleri.
- ⚡ **Zero-Lag & 60 FPS (İzole Süreç):** GUI, arka plandaki bağımsız bir süreçte (`multiprocessing`) çalışır. API istekleriniz veya ağır ses modelleriniz arayüzün akıcılığını etkilemez.
- 🔄 **6 Farklı Asistan Durumu:**
  1. `listening`: Standby / Uyandırma kelimesi (Wake-word) bekleme.
  2. `user_speaking`: Kullanıcı mikrofon girişi aktif (Equalizer dalgaları).
  3. `processing`: LLM çıkarımı, API istekleri veya araç (tool) çalıştırma.
  4. `assistant_speaking`: TTS ses çıkışı (Aurora spektrumu).
  5. `sleeping`: Uyku / Sessiz bekleme modu.
  6. `error`: Hata / Bağlantı zaman aşımı uyarısı.
- 🔊 **Canlı Ses Şiddeti (RMS) Desteği:** Mikrofon veya hoparlör ses genliğine göre gerçek zamanlı büyüyüp küçülen dinamik görselleştirici (`calculate_rms` dahildir).
- 💬 **Canlı Altyazı & Durum Rozeti:** Kullanıcının söylediği sözleri veya o anda çağrılan aracı (örn. `🌦️ Hava Durumu Sorgulanıyor...`) anlık olarak görüntüler.
- 🖱️ **Taşınabilir & Her Zaman Üstte (Always-on-Top & Draggable):** Ekranın istenilen yerine sürüklenebilir; çift tıklama ile sağ üst köşedeki orijinal konumuna geri döner.
- 🛠️ **Sıfır Dış Bağımlılık:** Python'ın dahili `tkinter` kütüphanesini kullanır. Ekstra bir GUI kütüphanesi (`PyQt`, `Pygame`, `Kivy` vb.) kurmanıza gerek yoktur.
- 💻 **Çapraz Platform:** macOS, Windows ve Linux işletim sistemlerinde pencere şeffaflığıyla tam uyumlu çalışır.

## 💻 Kendi Asistanınıza Entegre Etme

Arayüzü kendi projenize iki kolay yöntemle entegre edebilirsiniz:

### Yöntem 1: `BaseAssistantBridge` ile (Önerilen OOP Yaklaşımı)

Kendi asistan sınıfınızı `BaseAssistantBridge` sınıfından türeterek tüm durum yönetimini olay bazlı (event-driven) yapabilirsiniz:

```python
import time
from assistant_overlay_gui import BaseAssistantBridge, start_overlay, OverlayConfig

class MyVoiceAssistant(BaseAssistantBridge):
    def run_cycle(self):
        # 1. Dinleme modu
        self.on_idle("🎙️ Sizi dinliyorum...")
        time.sleep(1)

        # 2. Kullanıcı konuşmaya başladı
        self.on_user_speech_start("👤 Kullanıcı konuşuyor...")
        self.on_user_speech_chunk(audio_rms_volume=0.7, partial_transcript="Bugün hava nasıl?")
        time.sleep(1.5)

        # 3. LLM / İşlem modu
        self.on_processing_start("⚙️ Gemini yanıt hazırlıyor...")
        time.sleep(1.5)

        # 4. Asistan konuşuyor (TTS)
        self.on_assistant_speech_start(full_response_text="Bugün hava güneşli ve 24 derece.")
        self.on_assistant_speech_chunk(audio_rms_volume=0.8)
        time.sleep(2)

        # 5. Beklemeye dön
        self.on_idle()

if __name__ == "__main__":
    hud = start_overlay()
    assistant = MyVoiceAssistant(overlay=hud)
    try:
        assistant.run_cycle()
    finally:
        hud.stop()
```

---

### Yöntem 2: `OverlayController` ile Doğrudan Kontrol

Mevcut fonksiyonel asistan kodunuzun içine doğrudan tek satırlık çağrılar ekleyebilirsiniz:

```python
from assistant_overlay_gui import start_overlay, OverlayConfig

# Arayüzü başlat
config = OverlayConfig(width=240, height=180, margin_right=30, margin_top=40)
hud = start_overlay(config=config)

# Durumları tetikle:
hud.listening("🎙️ Uyandırma kelimesi bekleniyor...")
hud.user_speaking("👤 Dinleniyor...", volume=0.6, transcript="Bilgisayarı kapat")
hud.processing("⚙️ Komut yürütülüyor...")
hud.assistant_speaking("🤖 Yanıt veriliyor...", volume=0.8, transcript="İşlem tamamlandı.")
hud.sleeping("💤 Uyku moduna geçildi")
hud.error("⚠️ Mikrofon bağlantı hatası")

# Canlı ses dalgaları besleme (Mikrofon / Hoparlör stream döngüsünde):
hud.update_user_volume(0.85)       # 0.0 ile 1.0 arası değer
hud.update_assistant_volume(0.65)  # 0.0 ile 1.0 arası değer

# Kapatma
hud.stop()
```

## ⚙️ Yapılandırma & Özelleştirme

`OverlayConfig` sınıfı ile arayüzün boyutunu, konumunu, yazı tipini ve renklerini kolayca değiştirebilirsiniz:

```python
from assistant_overlay_gui import OverlayConfig, start_overlay

custom_config = OverlayConfig(
    width=260,                   # Genişlik (px)
    height=190,                  # Yükseklik (px)
    margin_right=20,             # Ekranın sağından boşluk
    margin_top=30,               # Ekranın üstünden boşluk
    border_radius=22,            # Yuvarlak köşe yarıçapı
    fps=60,                      # Hedef kare hızı
    always_on_top=True,          # Her zaman üstte kalsın mı?
    draggable=True,              # Sürüklenebilir olsun mu?
    title_font_family="Arial",   # Başlık fontu
    body_font_family="Helvetica" # Açıklama fontu
)

hud = start_overlay(config=custom_config)
```

### Özel Renk Teması Tanımlama:

İstediğiniz durum için kendi renk paletinizi tanımlayabilirsiniz:

custom_themes = {
