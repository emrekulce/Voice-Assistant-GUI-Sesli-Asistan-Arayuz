Türkçe
------
🎙️ Ne İşe Yarar?
Python tabanlı yapay zeka sesli asistanları için modern, şeffaf (glassmorphic), 60 FPS animasyonlu ve taşınabilir bir kayan arayüz (Floating HUD Overlay) sunar.

⚡ Neden Kullanmalısın?
• Sıfır Bağımlılık: Yalnızca Python standart `tkinter` kütüphanesini kullanır, harici GUI paketi gerektirmez.
• Sıfır Takılma (Zero-Lag): `multiprocessing` mimarisi sayesinde arka planda STT/LLM/TTS çalışırken arayüz 60 FPS akıcı kalır.
• Geniş Uyumluluk: Whisper, Gemini, GPT-4o, Claude, ElevenLabs, Ollama vb. tüm yapay zeka ve ses kütüphaneleriyle tak-çalıştır uyumludur.

🛠️ Detaylar
• 6 Durum: `listening`, `user_speaking`, `processing`, `assistant_speaking`, `sleeping`, `error`
• Görselleştirici: Gerçek zamanlı ses genliği (RMS) dalgaları ve Aurora spektrumu.
• Özellikler: Canlı altyazı/rozet desteği, sürükle-bırak, çift tıkla sıfırlama, özel renk temaları.
• Platform: macOS, Windows ve Linux tam uyumlu.


English
-------
🎙️ What Does It Do?
A modern, transparent (glassmorphic), 60 FPS animated, and draggable floating HUD overlay designed for Python AI voice assistants.

⚡ Why Use It?
• Zero Dependencies: Built purely with Python's standard `tkinter` library; no external GUI framework required.
• Zero-Lag & 60 FPS: Isolated `multiprocessing` architecture ensures UI stays fluid while processing STT/LLM/TTS tasks in the background.
• Universal Compatibility: Plug-and-play with any speech or AI stack (Whisper, Gemini, GPT-4o, Claude, ElevenLabs, Ollama, etc.).

🛠️ Details
• 6 States: `listening`, `user_speaking`, `processing`, `assistant_speaking`, `sleeping`, `error`
• Visualizer: Real-time audio amplitude (RMS) waves and Aurora spectrum.
• Features: Live subtitles & status badges, draggable, double-click reset, customizable color themes.
• Platform: Cross-platform (macOS, Windows, Linux).
